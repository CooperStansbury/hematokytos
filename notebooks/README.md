# Notebooks

A collection of Jupyter notebooks used for exploratory analysis, figure generation and
small utility tasks. The notebooks are organised into topical folders.

## Contents
- `analysis/` – Data exploration notebooks covering cell identity, reference atlas
  construction, trajectory inference and more
- `pipeline_support/` – Helper notebooks that accompany the workflow pipelines
- `make_colorbar.ipynb` – Generate standard colour palettes used in figures
- `nearest_neighbors.ipynb` – Example of computing nearest neighbour relationships

Each subfolder contains its own README describing the included notebooks.
