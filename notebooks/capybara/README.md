# Capybara Notebooks

Experiments related to using the Capybara tool for cell type similarity and label
transfer.

## Notebooks
- `build_capybara_ref.ipynb` – Construct reference matrices for Capybara
- `capybara_basename.ipynb` – Evaluate basenames for reference construction
- `capybara_cell_type.ipynb` – Compare Capybara scores across cell types
- `capybara_gomes.ipynb` – Check gene set enrichment metrics
- `capybara_select.ipynb` – Select relevant reference cells
- `capybara_test_r.ipynb` – R-based examples for running Capybara
- `cell_type_sim.ipynb` – Visualise similarity matrices
- `ground_up.ipynb` – De novo reference building workflow
- `quick_similarity.ipynb` – Rapid similarity checks
- `simplify_build_archive.ipynb` – Archive and simplify reference builds
- `error_compairison.ipynb` – Compare error rates between strategies
