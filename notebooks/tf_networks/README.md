# TF Network Notebooks

Analyses relating to transcription factor network inference.

## Notebooks
- `GEARS.ipynb` – Apply the GEARS algorithm
- `coexression.ipynb` – Co-expression network construction
- `scMINER_EDA.ipynb` – Exploratory analysis for scMINER
- `scMINER_centrality.ipynb` – Centrality metrics from inferred networks
- `scMINER_network_plots.ipynb` – Plotting utilities for networks
- `scMINER_r_network_qc.ipynb` – Quality control for SJARACNe outputs
- `trainfile.py` – Example training script
