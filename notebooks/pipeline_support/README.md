# Pipeline Support Notebooks

Utility notebooks used to test or assist the workflow pipelines. These notebooks
provide small analyses to inspect intermediate data products or generate
configuration files.

## Examples
- `basecaller_check.ipynb` – Inspect basecalling statistics
- `cell_cycle_analysis.ipynb` – Examine DeepCycle outputs
- `combine_anndata.ipynb` – Merge AnnData objects from multiple runs
- `intergration_hsc_scfib.ipynb` – Demonstrate cross-dataset integration
- `make_geneformer_emebeddings.ipynb` – Generate embeddings with Geneformer
- `make_sample_sheet.ipynb` – Build metadata tables for pipeline input
- `total_reads.ipynb` – Summarise sequencing depth
- `write_cc_anndata.ipynb` – Save processed cell cycle AnnData

Additional helper scripts such as `geneformer_utils.py` are stored here as well.
