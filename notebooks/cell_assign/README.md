# CellAssign Notebooks

Short examples demonstrating how to run the
[CellAssign](https://github.com/Irrationone/cellassign) algorithm to
annotate cells using marker genes. The notebooks rely on the combined
dataset produced in the reference analysis workflows.

## Notebooks
- `CELL_ASSIGN.ipynb` – Apply CellAssign on the combined dataset
- `CELL_ASSIGN_basename_deg.ipynb` – Use markers derived from DEGs for assignment
