# Capybara Notebooks

Experiments related to using the Capybara tool for cell type similarity and label transfer.

## Notebooks
- `build_capybara_ref.ipynb` – Construct reference matrices for Capybara
- `capybara_gomes.ipynb` – Check gene set enrichment metrics
- `capybara_select.ipynb` – Select relevant reference cells
- `capybara_test_r.ipynb` – R-based examples for running Capybara
- `cell_type_selection.ipynb` – Choose cells for building references

Older notebooks are kept in the `archive/` subfolder, including workflows such as `capybara_basename.ipynb`, `capybara_cell_type.ipynb` and various similarity comparisons.
