# Summary Notebooks

Miscellaneous notebooks for dataset summaries, metadata tables, and
general exploratory figures.

## Notebooks
- `anndata_summary.ipynb` – Inspect the contents of AnnData objects
- `combine_anndata.ipynb` – Merge individual samples into a single dataset
- `DEG_our_data.ipynb` – Differential expression across experiments
- `intergration_hsc_scfib.ipynb` – Example integration with fibroblast controls
- `marker_gene_expression.ipynb` – Plot expression of canonical markers
- `reprogram_v_control.ipynb` – Compare reprogrammed cells to controls
- `sequencing_summary.ipynb` – Summaries of sequencing metrics
- `total_reads.ipynb` – Calculate overall read counts per sample
- `basecaller_check.ipynb` – Inspect base calling metrics
- `make_sample_sheet.ipynb` – Generate a sample metadata sheet
- `write_cc_anndata.ipynb` – Save AnnData with cell-cycle annotations
