# Geneformer Notebooks

Exploratory work with the Geneformer transformer model for single-cell data,
including fine-tuning and perturbation experiments.

## Notebooks
- `geneformer_impulse.ipynb` – Test the impulse fine-tuning workflow
- `geneformer_pretrained.ipynb` – Use the pretrained model on our data
- `geneformer_perturbation.ipynb` – Simulate perturbations with Geneformer
- `geneformer_rank_value.ipynb` – Rank genes by embedding distance
- `make_geneformer_emebeddings.ipynb` – Generate embeddings for downstream use

A helper module `geneformer_utils.py` contains small utility functions used
across the notebooks.
