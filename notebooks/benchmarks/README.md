# Benchmark Notebooks

Notebooks assessing dataset integration strategies and comparing public
resources.

## Notebooks
- `atlas_benchmark.ipynb` – Benchmark integration using the reference atlas
- `dataset_benchmarks.ipynb` – Compare datasets produced with different protocols
- `distance_analysis.ipynb` – Calculate pairwise sample distances
- `ElasticNet.ipynb` – Elastic net regression for feature selection
- `get_gomes.ipynb` – Download count data from Gomes et al.
- `get_setty_data.ipynb` – Retrieve processed counts from Setty et al.
